# 링크 텍스트 파일 다운로더

웹페이지에 포함된 다운로드 링크를 검색하고, 링크에 표시된 텍스트를 파일명으로 저장하는 Python GUI 프로그램입니다.

## 주요 기능

- 웹페이지 URL에서 다운로드 링크 검색
- 확장자별 필터링 (예: `zip`, `pdf`, `egg`)
- 전체 다운로드 및 선택 다운로드
- 저장 폴더 지정 및 설정 저장
- 기존 파일 건너뛰기, 다운로드 결과 로그 확인

## 설치 및 실행

Python 3이 필요합니다.

```bash
pip install requests beautifulsoup4
python downloader_gui.py
```

Windows에서는 `start.vbs`를 더블 클릭해 콘솔 창 없이 실행할 수도 있습니다. 이 경우 `pythonw.exe`가 실행 가능한 환경이어야 합니다.

## 사용 방법

1. **웹페이지 URL**을 입력합니다.
2. 필요한 경우 **확장자**를 입력합니다. 비워두면 확장자 필터 없이 검색합니다.
3. **저장 폴더**를 지정하고 **링크 검색**을 누릅니다.
4. 검색 결과에서 **전체 다운로드** 또는 **선택 다운로드**를 누릅니다.
5. 하단 로그에서 다운로드 결과를 확인합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `downloader_gui.py` | GUI 및 다운로드 기능 |
| `start.vbs` | Windows용 간편 실행 스크립트 |
| `downloader_settings.json` | 저장 폴더 및 확장자 설정 |

## 참고 사항

- 검색 대상은 HTML의 `<a href>` 링크이며, 링크에 표시된 텍스트를 파일명으로 사용합니다.
- 확장자 필터는 실제 다운로드 URL이 아닌 **링크 텍스트**를 기준으로 적용됩니다.
- 로그인이나 JavaScript 실행이 필요한 페이지에서는 링크를 찾지 못할 수 있습니다.
- 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 건너뜁니다.
